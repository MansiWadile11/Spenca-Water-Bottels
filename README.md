# 💧 Spenca Water Bottle 

A sleek, responsive, and modern product website for **Spenca Water Bottle**, designed to promote hydration with style. This site highlights the bottle's features, encourages eco-conscious living, and provides an engaging user experience for customers.

---

## 🛍️ Project Overview

This project showcases a premium reusable water bottle through an attractive and informative landing page. Built with modern frontend technologies, the website focuses on clear branding, product benefits, and mobile responsiveness.

---

## 🌟 Features

- 💧 Hero section with product image and tagline  
- 🧊 Feature highlights (insulated, BPA-free, eco-friendly)  
- 🎥 Product promo section (video or animation)  
- 🎨 Modern, minimal design using soft gradients or brand palette  
- 🛒 CTA buttons (Buy Now, Learn More)  
- 📱 Fully responsive for mobile and tablet  
- 🖼️ Product image gallery or slider *(optional)*  
- 🧾 Footer with contact & social links

---

## 🛠️ Tech Stack

- **HTML5** – Structure  
- **CSS3 / SCSS** – Styling & layout  
- **Bootstrap 5** *(optional)* – Grid & responsiveness  
- **JavaScript** – Interactivity, animations  
- **Font Awesome / Icons** – Visual enhancements
